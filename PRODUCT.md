# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Internal team managing geospatial assets.

## Product Purpose
Manage and visualize geospatial assets through custom map integrations.

## Positioning
Custom integration of specific local maps and routes tailored to the internal team's needs, differing from generic mapping tools.

## Operating Context
Internal workflows for geospatial asset management, planning, and evaluation.

## Capabilities and Constraints
- Must use the existing Python backend.
- Must integrate with existing `data_loader.py` scripts.

## Evidence on Hand
- Existing Python backend and data scripts.
- Local map data handling.

## Product Principles
1. Maintain seamless integration with the existing Python backend and data pipelines.
2. Prioritize clarity, precision, and ease of use for the internal team managing geospatial assets.
3. Ensure efficient rendering and interaction with custom local maps and routes.
